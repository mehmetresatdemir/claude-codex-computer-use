## 2. `node_repl` nasıl çalışıyor

- **İkili**: `cua_node/bin/node_repl` Rust (tokio, rmcp, reqwest, sentry, OTEL). stdio MCP sunucusu; araçlar `js`, `js_reset`, `js_add_node_module_dir`, gizli `turn_ended`. `js` açıklaması (ikiliden): "Execute JavaScript in a persistent `node_repl` with top-level await. Top-level bindings persist until `js_reset`… dynamic imports such as `await import("playwright")`; top-level static imports and `node:process` are unavailable. `nodeRepl.write(value)` for output, `await nodeRepl.emitImage(image)` for images… `nodeRepl.cwd/homeDir/tmpDir/requestMeta`… **default timeout 30000 ms**; increase `timeout_ms`…".
- **Üç süreç**: Rust süpervizör ↔ (JSONL stdout) ↔ `trusted-worker.js` (güvenilir servisler: `@oai/sky/service`, `@oai/browser-desktop/service`; `registerHooks` ile yalnızca `NODE_REPL_TRUSTED_CODE_PATHS` altındaki modüller yüklenebilir) ve `kernel.js` (modelin JS'i `node:vm` içinde, meriyah ile ayrıştırılıp "auto review"e tabi; `codex_strict_auto_review`, `NODE_REPL_FORCE_STRICT_AUTO_REVIEW`, `NODE_REPL_ENFORCE_MODEL_CHECK`). Çekirdek güvenilir servise `trusted_service_request` mesajıyla erişir (`NODE_REPL_TRUSTED_RPC_ENABLED=1`).
- **Ayrıcalıklı köprü (privileged-node-repl.js)**: `nodeRepl.nativePipe.createConnection(path)` → Rust'a `native_pipe_request{op:connect,path}`; Unix soketini **Rust süreci açar** (`NODE_REPL_SANDBOX_ALLOWED_UNIX_SOCKETS`, `NODE_REPL_DENIED_PATHS`). `nodeRepl.launchServices.openApplication({applicationPath|bundleIdentifier})` → `launch_services_action`. `nodeRepl.createElicitation` (MCP form elicitation; onay diyalogları `codex_approval_kind: mcp_tool_call`, `connector_id: computer-use`), `nodeRepl.authenticatedFetch` (`authenticated_fetch` → Rust → kendi başlattığı `codex app-server --listen stdio://` üzerinden auth token; `src/codex_app_server_auth.rs`), `config_action` → `config/batchWrite`, `nodeRepl.withSuspendedTimeout({run,timeoutMs})` (suspend/resume_timeout), `emit_audio` (`NODE_REPL_ENABLE_AUDIO`).
- **Sandbox**: `~/.codex/node_repl/active_execs/<execId>.json` kayıtları `{"sandbox":"seatbelt"|"seccomp","nodeReplPid","kernelPid","sessionId","turnId"}`; "js sandbox changed; kernel reset" mesajı var. macOS'ta çekirdek seatbelt ile sarılıyor (`codex_sandboxing` modülü, `/usr/bin/sandbox-exec`).
- **Önceden yüklü kütüphaneler** (`cua_node/lib/node_modules`): `@oai/sky`, `@oai/cua` (`tinyskyAlt`, `tinyskyBrowser`), `@oai/cua-repl`, `@oai/browser-desktop`, `playwright`, `playwright-core`, `sharp`, `@img/*`, `pixelmatch`, `pngjs`, `jpeg-js`, `classic-level/abstract-level`, `@statsig/js-client`, `semver`, `corepack`.
- **cua_repl vs node_repl**: `cua-repl.mjs` = NodeREPL'i `NODE_REPL_JS_BANNER=await import("@oai/cua/tinyskyAlt")` ile başlatır; `cua` global'i (`cua.getState/getApp/getTab/createBrowserTab/getBrowser`, `App.getAXState/getScreenshot/click/drag/scroll/selectText/setValue/performSecondaryAction/paste/pressKey/typeText`) hazır gelir; ilk çağrıda yalnızca tek API çağrısı yapılması isteniyor (`instructions/macos/description.md`). Eski yol: `globalThis.sky = (await import("@oai/sky")).sky; sky.get_app_state({app})`.
- **Çıktı sınırı**: `.mcp.json` → `tools.js.output_token_limit: 25000`; `startup_timeout_sec: 120`; `omit_tools_from: ["code_mode","deferred"]`. Sky istemci tarafı istek zaman aşımı `timeoutSeconds` varsayılan **120 s**; native pipe çerçevesi 4 bayt LE uzunluk + JSON, **8 MB** üst sınır; ilk bağlantı 250 ms, servis başlatma sonrası 5 s.
- **Diff**: AX ağacı varsayılan diff (`disableDiff`/`disableDiffing`); servis ~1 s "settle" bekler (SKILL.md: "It waits about 1 second…"); eylemden sonra `get_app_state` yeniden çağrılır.
- **turn_ended**: eklenti kancaları (`Stop`, `Interrupt`, `SubagentStop`) `cua_repl.turn_ended` / `node_repl.turn_ended` MCP aracını çağırır; config.toml `notify = [SkyComputerUseClient, "turn-ended"]` ile istemciye de bildirilir (`agent-turn-complete`).

## 3. `codex sandbox` başlatıcısı

- `codex-cli/bin/codex` 10 satırlık sh: `exec "$bin_dir/../CodexCLI.app/Contents/MacOS/codex" "$@"`. İkili `Identifier=codex, TeamIdentifier=2DC432GLL2` (Apple Developer ID imzalı, Rust, 240 MB; sürüm 0.159.2).
- `sandbox --sandbox-state-json <json> -- <program> [args]`: `SandboxState{permissionProfile{type: disabled|…, fileSystem{type: unrestricted|…}}, sandboxCwd, useLegacyLandlock, codexLinuxSandboxExe}`. `permissionProfile.type=disabled` ile seatbelt profili uygulanmaz; yalnızca `exec` eder.
- Seatbelt şablonu (ikilideki strings): `(version 1) (deny default) (allow process-exec) (allow file-read*) (allow file-read* (subpath "/Applications"|"/etc"|"/Library/Preferences"|"/opt/homebrew/lib"|"/usr/local/lib"))`, `(allow file-read* file-write* (literal "/dev/null"|"/dev/ptmx"|"/dev/tty") (regex "^/dev/ttys[0-9]+$"))`, `(allow mach-lookup (global-name "com.apple.audio.*"|"com.apple.PowerManagement.control"|"com.apple.system.opendirectoryd.libinfo"|"com.apple.TrustEvaluationAgent"))`, `(deny mach-lookup (xpc-service-name-prefix ""))`, `(allow network-outbound (remote ip "localhost:*") (remote ip "*:53") (remote unix-socket (subpath (param "ALLOW_UNIX_SOCKETS_N"))))`, `(deny file-ioctl (ioctl-command TIOCSTI))`, `(deny system-fcntl …)`; yazma izinleri `(subpath (param "WRITABLE_ROOT_N"))` + `(require-not (subpath (param …)))`; `/usr/bin/sandbox-exec -D param=… -p profile` ile çalıştırır. CLI bayrağı: `--allow-unix-sockets` ("Allow the sandboxed command to bind/connect AF_UNIX sockets rooted at this path").
- Neden servis bu zinciri kabul ediyor: servis ikilisi peer'ın `_senderParentTeamID` / `_senderResponsibleTeamID` (+ `sender_parent_signing_id`, `sender_responsible_bundle_id` telemetri alanları) kontrolü yapıyor; kabul listesi `com.openai.codex{,.alpha,.beta,.dev,.nightly}`, `com.openai.chat{,.alpha,.beta,.nightly,.mac-debug}`, `com.openai.atlas{,.alpha,.beta}`, `com.openai.sky.app`, team `2DC432GLL2`. `codex sandbox` ebeveyn olunca ebeveynin team ID'si OpenAI oluyor; doğrudan `claude → SkyComputerUseClient` zincirinde ebeveyn Anthropic imzalı olduğundan −10000. Codex'in kendi yolu da aynı: `app-server (codex) → sh launcher → SkyComputerUseClient`. Electron'un ayrı "browser-use native pipe peer authorizer" (mode=packaged) ve "dynamic-app-tools" borusu da süreç soyağacına bakıyor (loglarda `untrusted-process-ancestry` reddi; 2026-10-01 15:30:50'de ~30 adet patlama, 22:57'de son).

## 7. Sarmalayıcıya (`claude-codex-computer-use/server.mjs`) aktarılabilecek 8 somut iyileştirme

1. **Doğru sağlık kontrolü**: `status` şu an `pgrep` ile 4 süreç adına bakıyor. Gerçek kriter servis soketi: `~/Library/Group Containers/2DC432GLL2.com.openai.sky.CUAService/IPC/computeruse.sock` var mı + `lsof -U | grep computeruse.sock` ile dinleyen pid (`SkyComputerUseService`) + sürüm (`Codex Computer Use.app/Contents/Info.plist` CFBundleShortVersionString, istemci ile aynı mı → −10013 önleme). `codex app-server` sadece ChatGPT.app'in açık olduğunu gösterir; servis ChatGPT ana süreci (50941) tarafından "managed service" olarak başlatılır, app-server'ın değil → `-10005 app-server exited` sonrasında ChatGPT.app'i açmak doğru, ama bekleme koşulu soket + `ping` olmalı (Sky kütüphanesi 250 ms/5 s ile dener).
2. **Ortam temizliği istemci spawn'ında**: bridge `env: process.env` ile `CODEX_APP_TOOLS_PIPE_PATH`, `CODEX_TASK_WORKSPACE_VERIFYING_IDENTITY`, `CLAUDE_CODE_*` değişkenlerini `codex sandbox`/istemciye geçiriyor. Sarmalayıcı bridge'i başlatırken `CODEX_*` (CODEX_HOME hariç) ve `CLAUDE_*`'ı süzsün; Electron'un dynamic-app-tools borusuna istenmeyen bağlantı/ret olasılığı ve `untrusted-process-ancestry` gürültüsü azalır.
3. **İstemci yolu tercihi**: `COMPUTER_USE_CLIENT_PATH` ChatGPT.app içindeki `@oai/sky/Codex Computer Use.app` istemcisine işaret ediyor; Codex kendi eklentilerinde `$CODEX_HOME/computer-use/…` kullanıyor. Sürüm eşitliği her güncellemede kontrol edilsin (ikisi şu an 26.924.1001281); farklıysa `~/.codex/computer-use` tercih edilsin (servisle birlikte güncellenen kopya o).
4. **Messages / Computer History / Record & Replay köprü üzerinden**: aynı imzalı zincir (`codex sandbox -- SkyComputerUseClient {messages|computer-history|event-stream} mcp`) ile üç ek MCP sunucusu açılabilir. Sarmalayıcıya `--surface` seçeneği (veya üç ayrı MCP kaydı) eklenir; initialize handshake'i aynen (bridge zaten kaydedip tekrar oynatıyor). Not: eklentiler Codex'te kurulu değil ama istemci ikilisi tüm sunucuları içeriyor; servis tarafı onay diyalogları (mesaj + alıcı onayı, sohbet başına okuma izni) aynen çalışır — köprü bunları `createElicitation` benzeri biçimde Claude'a aktarmalı, otomatik kabul etmemeli.
