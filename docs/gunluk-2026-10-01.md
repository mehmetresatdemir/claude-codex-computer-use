# Günlük — 2026-10-01

Bir Claude Code (Desktop) oturumunda, Codex'in Computer Use bileşenini Claude'dan kullanılır hale getirme çalışmasının adım adım kaydı. Hatalar ve çıkmaz sokaklar da dahil; başkası aynı yere düşmesin diye.

## 1. Başlangıç durumu

- Mac'te `codex-computer-use` adında bir MCP kaydı vardı; `SkyComputerUseClient mcp`'yi **doğrudan** başlatıyordu.
- Bağlantı kuruluyor, araçlar yükleniyor ama her çağrı `-10000: Sender process is not authenticated` veriyordu.
- Hedef: [songkeys/claude-codex-computer-use](https://github.com/songkeys/claude-codex-computer-use) köprüsünü kurup bunu aşmak.

## 2. Köprü kurulumu

1. README okundu: köprü, istemciyi ChatGPT.app içindeki imzalı `codex sandbox` ile başlatıyor; servis bu soy ağacını kabul ediyor.
2. Elle test: `npx -y claude-codex-computer-use@latest` ile JSON-RPC `initialize` + `list_apps`. **Başarılı**; açık uygulama listesi döndü. Uyarı: `EBADENGINE node >=22.14` (sistemde Node 20 vardı).
3. Eski kayıt silinip aynı adla köprü kaydedildi (`claude mcp add … -e COMPUTER_USE_CODEX_LAUNCHER_PATH=… -e COMPUTER_USE_CLIENT_PATH=…`). Yeni oturum gerektiği not edildi.

## 3. Node 22

- `nvm install 22` en yeni sürümü (22.23.3) indirdi, **checksum tutmadı**, kaynaktan derlemeye geçti (çok uzun). Durduruldu, bozuk sürüm kaldırıldı.
- Diskte sağlam v22.20.0 vardı; kayıt ona bağlandı. `nvm alias default 22.20.0`, `nvm reinstall-packages 20.19.4` ile global paketler taşındı.

## 4. İlk gerçek görev: Freeform'da resim

- Oturum eski kaydı taşıdığı için Codex aracı hâlâ `-10000` verdi → Claude'un kendi Computer Use'uyla devam edildi.
- Claude aracı: arka plan modunda Freeform menüleri pasif; tam ekran moduna geçildi. Şekil ekleme, taşıma ve boyutlandırma `mouse_down/move/up` ile çalıştı ama her adım bir model turu + ekran görüntüsü → yavaş. Bir sürükleme şekli taşımak yerine metin düzenleme moduna aldı; tutamaç ıskalandı vb.
- Oturum yeniden yüklenince köprü devreye girdi: `get_app_state` **çalıştı**. Codex ile pano açma, şekil ekleme, pencere büyütme hızlıydı (öğe indeksi ile).
- **Codex `drag` Freeform'da şekil taşımadı** (orijinal ve ölçekli koordinatlarla denendi); tutamaçlara `set_value` da etkisiz. Koordinatların orijinal çözünürlükte (2560×1300) olduğu doğrulandı.
- Çözüm: Pillow ile `ev.png` üretildi; Codex ile Insert > Choose File > ⌘⇧G > yol > Return > Insert. Eklendi. Deneme karesi silindi.

## 5. "Kota gidiyor mu?"

- Süreçler listelendi; köprü/istemci/servis süreçlerinde `lsof -i` ile **hiç TCP bağlantısı yok**.
- Unix soket: `…/Group Containers/2DC432GLL2.com.openai.sky.CUAService/IPC/computeruse.sock`.
- `strings`: yalnızca telemetri/feature-flag ve auth/profile adresleri; model adresi yok.
- Dışarı bağlı `codex` süreçleri ChatGPT.app'in kendi `app-server`/`exec-server`'ı (ebeveyn ChatGPT.app).
- Sonuç: **kota harcanmıyor.** Hafızaya ve CLAUDE.md'ye yazıldı.

## 6. "Codex neden daha hızlı?"

- Köprüye doğrudan bağlanıp ölçüldü: başlatma 1,1 sn, soğuk okuma 1,2 sn, **sıcak okuma 70 ms**, `list_apps` 10 ms.
- Yavaşlık araçta değil; her adımın bir model turu olmasında ve 159 KB görüntünün her yanıtta gelmesinde.

## 7. Sarmalayıcı yazımı (codex-cua-plus)

- Köprü paketi incelendi: tek dosya, 614 satır JSON-line proxy. Üstüne kendi MCP sunucumuz yazıldı (`server.mjs`, bağımlılıksız).
- Eklenenler: `batch`, `include_screenshot` (varsayılan kapalı), `press_key.repeat`, `open_path_in_dialog`, `sleep_ms`, idle 10 dk.
- Test: `tools/list` 12 araç; görüntüsüz durum 3 KB; `batch` çalıştı.
- Kayıt sarmalayıcıya çevrildi (`claude mcp add … node server.mjs`), `✔ Connected`.

## 8. Çıkmaz sokaklar ve düzeltmeler

- **Takılı menü:** bir test Insert menüsünü açık bıraktı; `batch` içindeki Escape'ler Freeform'u All Boards'a döndürdü; Codex ağacı pasif menüde kaldı. `Escape` ve `Cancel` ikincil eylemi düzeltmedi. Claude aracıyla pencerenin boş alanına tıklamak düzeltti.
- **Yetim süreçler:** harness `terminate` edince sarmalayıcı üst akışı kapatmıyordu → SIGTERM/SIGINT/SIGHUP işleyicisi eklendi; doğrulandı.
- **`-10005 codex app-server exited`:** ChatGPT.app kapanmıştı; servis onun `app-server`'ına bağlı. `open -g -a ChatGPT` ile arka planda açıldı, 5 sn'de app-server, servis geldi. Sarmalayıcıya otomatik açma + bir kez yeniden deneme eklendi.
- **Uçtan uca test:** pano aç → Insert → Choose File → `open_path_in_dialog` → ekle → kopyayı sil: **5,6 sn**, 0 ara model turu (elle 7 tur sürmüştü).

## 9. Notlar

- Claude'un Computer Use'u ile Codex'inkini birlikte tutmak faydalı: biri takılınca diğeri bağımsız gözlem verir.
- Araçları olabildiğince az model turuyla kullan: ara anlatım yapma, öngörülebilir adımları `batch`'e koy, görüntüyü yalnızca gerektiğinde iste.
